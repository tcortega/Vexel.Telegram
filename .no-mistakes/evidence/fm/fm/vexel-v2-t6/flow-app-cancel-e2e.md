# An app that owns /cancel, end to end

A bot that arms text steps with `flow.PromptAsync<TRequest>()` is compiled with the
Immediate and Vexel generators, loaded, registered through its generated
`Add{Assembly}Telegram()`, and run in a real host against a fake Telegram Bot API server
over HTTP. Every line below is a real message on the wire.

## 1. The chat, as the user sees it

```text
user  >  /note
  bot <  Type your note.
user  >  /cancel
  bot <  App cancel here - your note is still open.
user  >  buy milk
  bot <  Saved note: buy milk
```

### What each turn proves

| User sends | Bot replies | Behaviour |
| --- | --- | --- |
| `/note` | `Type your note.` | arms the note step |
| `/cancel` | `App cancel here - your note is still open.` | the app's own [Command("cancel")] runs; the built-in never fires |
| `buy milk` | `Saved note: buy milk` | the step is still armed, because the app's cancel chose not to clear it |
