# Multi-turn conversation flow, end to end

A bot that arms text steps with `flow.PromptAsync<TRequest>()` is compiled with the
Immediate and Vexel generators, loaded, registered through its generated
`Add{Assembly}Telegram()`, and run in a real host against a fake Telegram Bot API server
over HTTP. Every line below is a real message on the wire.

## 1. The chat, as the user sees it

```text
user  >  /signup
  bot <  What's your name?
user  >  Ada Lovelace
  bot <  Nice to meet you, Ada Lovelace. How old are you?
user  >  thirty six
  bot <  Something went wrong - try again, or /cancel.
user  >  36
  bot <  Registered Ada Lovelace, age 36.
user  >  are you still there?
  bot <  (silence)
user  >  /signup
  bot <  What's your name?
user  >  /whoami
  bot <  (silence)
user  >  Grace Hopper
  bot <  Nice to meet you, Grace Hopper. How old are you?
user  >  /cancel
  bot <  Cancelled.
user  >  42
  bot <  (silence)
user  >  /signup
  bot <  What's your name?
         ... 16 minutes pass ...
user  >  Alan Turing
  bot <  (silence)
```

### What each turn proves

| User sends | Bot replies | Behaviour |
| --- | --- | --- |
| `/signup` | `What's your name?` | command arms the first step |
| `Ada Lovelace` | `Nice to meet you, Ada Lovelace. How old are you?` | plain text goes to the armed step, which saves a draft and re-arms |
| `thirty six` | `Something went wrong - try again, or /cancel.` | step throws: generic reply, step stays armed |
| `36` | `Registered Ada Lovelace, age 36.` | retry succeeds; draft survived the throw; no re-arm auto-completes the flow |
| `are you still there?` | _(silence)_ | flow is over, so plain text is unrouted and the bot stays silent |
| `/signup` | `What's your name?` | arm again to test interruptions |
| `/whoami` | _(silence)_ | unknown command mid-flow: command miss, and it does NOT get eaten as step input |
| `Grace Hopper` | `Nice to meet you, Grace Hopper. How old are you?` | the step was still armed after the unknown command |
| `/cancel` | `Cancelled.` | built-in /cancel wins over the armed step and clears it |
| `42` | _(silence)_ | nothing armed after cancel, so the answer is unrouted |
| `/signup` | `What's your name?` | arm once more, then walk away |
| `Alan Turing` | _(silence)_ | 16 minutes later the 15m TTL has expired, so the late answer is unrouted |
